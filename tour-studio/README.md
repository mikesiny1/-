# מפלס — סטודיו סיורים וירטואליים לנדל״ן

אפליקציית ווב לסוכני נדל״ן ומשווקים: מעלים **תוכנית דירה** או **צילומי נכס**, עונים על בריף עיצוב קצר,
ומקבלים סיור וירטואלי מרוהט, סרטון ממותג לרשתות החברתיות וטקסטים מוכנים לשליחה ללקוח.

## מה יש בפנים

| שלב | מה קורה |
| --- | --- |
| **ניהול נכסים** | תיק נכסים עם סטטוסים (טיוטה / בעבודה / מוכן לפרסום / נשלח), מונים ויומן שליחות לכל נכס. |
| **פרטי הנכס והלקוח** | כתובת, חדרים, שטח, מחיר, ופרטי הלקוח שמקבל את הסיור. |
| **תוכנית ותמונות** | העלאת תוכנית (JPG/PNG) ו/או צילומים. תמונות גדולות מוקטנות אוטומטית. |
| **בריף עיצוב** | שאלות של מעצב: להציג מרוהט? קהל יעד, רמת גימור, סגנון (7 סגנונות), תאורת יום/ערב — כולל המלצת סגנון מנומקת. |
| **קריאת התוכנית** | זיהוי קירות, חדרים ושטחים, הערכת קנה מידה לפי שטח הדירה, כיול ידני בשתי נקודות, וזיהוי אוטומטי של סוג כל חדר (כולל ממ״ד לפי עובי קירות ומרפסת לפי עובי מעקה). |
| **הלבשת תמונות** | "הצעת מעצב" לכל סוג חדר, גרירה, שינוי גודל וזווית של פריטי ריהוט בסגנון שנבחר, ומצב לפני/אחרי. |
| **הסיור** | מודל תלת-ממדי של הדירה מהתוכנית: סיור מודרך (פתיח מלמעלה ואז מעבר חדר-חדר), הליכה חופשית, ותצוגת בובות עם שמות ושטחי חדרים. אפשר לשנות סגנון, להדליק/לכבות ריהוט ולעבור לערב — בזמן אמת. כולל הערות מעצב לכל חדר והערכת עלות הלבשה פיזית. |
| **פרסום ושליחה** | הפקת סרטון MP4 בפורמט ריל/סטורי (9:16), פיד (4:5) או יוטיוב (16:9) עם פתיח, כיתובי חדרים, מחיר, כרטיס סיום ממותג ומוזיקת רקע; תמונת שער; טקסטים לאינסטגרם, פייסבוק ווואטסאפ; שליחה ללקוח בוואטסאפ או במייל ושיתוף ישיר מהנייד. |
| **פרופיל משרד** | שם משרד, סוכן, טלפון, רישיון, צבע מותג ולוגו — נצרבים בכל סרטון. |

## הרצה

```bash
cd tour-studio
npm install
npm run dev      # פיתוח: http://localhost:5173
npm run build    # בנייה ל-dist/ — אתר סטטי שאפשר להעלות לכל אחסון
```

בדף הבית יש כפתור **"נכס לדוגמה"** שפותח פרויקט עם תוכנית אדריכלית מוכנה — הדרך המהירה לראות את כל התהליך.

### העלאה לאוויר
הקובץ `.github/workflows/deploy-tour-studio.yml` בונה ומפרסם את האתר ל-GitHub Pages בכל דחיפה ל-`main`.
צריך להפעיל פעם אחת: **Settings → Pages → Source: GitHub Actions**.

## איך זה עובד

- **קריאת תוכנית** (`src/lib/plan.ts`): התמונה מומרת למסכת "דיו", קווים דקים (טקסט, קווי מידה, סימוני ריהוט, קשתות דלתות) מוסרים
  בפתיחה מורפולוגית, והשאר הם קירות. פנים הדירה מזוהה אחרי גישור פתחי חלונות, החדרים הם אזורים פנויים כשהדלתות "נסגרות" זמנית,
  וקווי זיגוג דקים מפרידים בין סלון למרפסת. איים שנוצרו מסימוני ריהוט מתמזגים חזרה לחדר.
- **תלת-ממד** (`src/three/`): Three.js. קירות ורצפות נבנים מהמסכה, הריהוט נבנה פרוצדורלית לפי הסגנון (חומרים, צבעים, רגליים, ריפוד),
  ומוצב לפי חוקי עיצוב — ספה על הקיר המלא, מיטה עם ראש לקיר, ארון מול/לצד המיטה וכו׳. נקודת הצילום בכל חדר נבחרת כמו צלם נדל״ן:
  מהצד הרחוק, באלכסון, בלי להיתקע ברהיטים. המסלול בין החדרים מחושב ב-A* ועוקף ריהוט.
- **הלבשת תמונות**: כל פריט ריהוט מרונדר בתלת-ממד לתמונה שקופה עם צל, בשלוש זוויות, ומונח על הצילום.
- **וידאו**: הקלטה בזמן אמת של קנבס (MediaRecorder) עם שכבות טקסט, ומוזיקה מסונתזת ב-Web Audio. ב-Chrome/Edge עדכניים מתקבל MP4.

## מגבלות שכדאי להכיר

- **הכול נשמר מקומית בדפדפן** (IndexedDB) — אין שרת ואין חשבונות. מחיקת נתוני הדפדפן מוחקת את הנכסים. לעבודת צוות צריך להוסיף צד שרת.
- קריאת התוכנית עובדת הכי טוב עם תוכנית נקייה שבה הקירות בקו עבה וכהה. בתוכניות מורכבות כדאי לעבור על סוגי החדרים ולכייל קנה מידה.
  PDF צריך לייצא קודם לתמונה.
- ההלבשה הווירטואלית היא **סקיצת המחשה**, לא רינדור פוטוריאליסטי; בסרטון מופיעה הערה שהריהוט אינו כלול בנכס.
- הפקת הסרטון רצה בזמן אמת — סיור של דקה וחצי לוקח דקה וחצי, וצריך להשאיר את הלשונית פתוחה.
- וואטסאפ ומייל נפתחים עם הודעה מוכנה; את קובץ הסרטון מצרפים ידנית (מגבלה של הדפדפן). בנייד כפתור "שיתוף" שולח את הקובץ ישירות.
